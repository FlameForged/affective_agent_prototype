Affective Agent Prototype

This repository contains an exploratory Python prototype modeling affective state, symbolic interaction, memory logging, and autonomous behavior loops in an AI-inspired agent.

The project was originally built in March 2025 as part of my early independent exploration of human-AI interaction dynamics. It later became conceptually related to my research paper:

Third-Space Cognition: Interaction-Level Dynamics in Sustained Human-AI Coupling
Zenodo DOI: 10.5281/zenodo.18679265

What It Does

The prototype defines an AffectiveAgent class with internal state variables such as:

* energy level
* field strength
* memory categories
* interaction modes
* environment shifts
* rest and wake states
* autonomous heartbeat cycles

The agent can receive inputs, update its internal state, log memory events, simulate mood signatures, shift contexts, and run autonomous cycles using randomized state transitions.

Why This Exists

This is not a production AI system or machine learning model. It is a conceptual and exploratory simulation designed to model questions such as:

* How might an artificial agent represent affective state?
* How can interaction history be logged and surfaced?
* What happens when symbolic state, user input, and autonomous loops are combined?
* How can code be used to think through human-AI interaction patterns?

Research Connection

This prototype reflects early thinking around interaction-level dynamics, affective modeling, conversational feedback, and the design of systems that respond to user input over time.
